§ 2

Practices

  • Least-privilege IAM roles, policies, and security groups throughout
  • All AWS resources encrypted with customer-managed KMS keys
  • Alarms on ALB, target groups, EC2, Kinesis, SQS, and RDS — each emailing on trigger
  • Public internet exposure limited via private subnets and VPC endpoints
  • All traffic encrypted with SSL; mTLS inside the cluster
  • CI enforces testing before deploy; IaC guarantees reproducibility
