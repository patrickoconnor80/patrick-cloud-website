How it works

  • Universe - S&P 500 + 400 + 600 (~1,500 tickers), so every candidate already clears the market-cap filter below.
  • Filters - last close above the 200-day SMA, last close above the 8-day EMA, market cap over $1B.
  • Ranking - survivors sorted by trailing EPS, top 5 shown.
  • Runs daily on a Lambda triggered by EventBridge; results are written straight to this site's S3 bucket and CloudFront is invalidated so the table below is always fresh.

This is a data screen, not investment advice.
