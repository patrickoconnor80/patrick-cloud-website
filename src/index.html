About

I'm a cloud engineer. This site started as a portfolio for the infrastructure work — a real AWS stack, deployed entirely through Terraform so it's reproducible, tracking its own analytics through Snowplow and modeling that data in Databricks. It's since become the place I publish everything else too.

The infrastructure gets destroyed between demos to keep costs down, so consoles will read as offline unless I've spun the stack back up.
